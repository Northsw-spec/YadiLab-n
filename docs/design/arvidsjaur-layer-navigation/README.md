# AV-001 — Arvidsjaur navigation-layer standard

This directory is the versioned source of truth for AV-001 in PR #105. The
binding contract, implementation prompt, machine-readable AV-P0 controls,
source/provenance notes and the exact reference image are kept together so a
future session does not depend on chat history.

Reference image: `reference/Arvidsjaur_Standarden_2026-11-12.png`

SHA-256: `8eb2417aef038a2c02dc9866f49709874c4e2ded2c88fd5442df98d8bfed834c`

The image is normative reference material supplied for AV-001. It is not a
claim that the current render has visual approval. Visual review remains
`PENDING_USER` until the user explicitly approves the real Chromium evidence.

Implementation entrypoints:

- `ui/src/canvas/hierarchical-topology.ts` — source-derived scopes and groups.
- `ui/src/canvas/topology-elk-adapter.ts` — nested ELK node/port/orthogonal-edge layout.
- `layout/src/elk-backend.ts` and `layout/src/types.ts` — existing ELK backend contract.
- `ui/app/main.mjs` — camera, scope navigation and rendered evidence attributes.

The P0 control matrix is `controls/AV001_P0_krav.json`. Evidence generated by
the compiled Chromium acceptance runs belongs under the same directory's
`evidence/` subtree; a report must preserve exact commit and scope IDs and must
not convert `PENDING_USER` into `PASS`.
